# 商品抠图流程说明（v3.13）

## 1. 这份文档解释什么

本文只说明当前工作台中的商品抠图，不讨论桌面识别、摆位、阴影或最终合成。

当前抠图坚持一个不可变原则：

- 商品 RGB 像素只能来自原始商品图。
- 模型只产生 Alpha 蒙版。
- 不使用扩散模型重画商品。
- 不允许模型修改文字、花纹或高频纹理。

界面中的分数现在叫“自动可信度”，不是人工真值评分，也不是最终视觉评分。

自动系统没有真实标注 Alpha，因此不能诚实地声称某次抠图是 100 分。

## 2. 当前使用的模型

### 2.1 U2Net

- 调用方式：`rembg` 2.0.77。
- 运行格式：ONNX。
- 推理后端：ONNX Runtime。
- 模型名称：`u2net`。
- 当前用途：通用前景候选之一。
- 优势：盆栽、深色花盆、形状连续的常见商品通常较稳定。
- 已知问题：复杂室内背景中可能只抓住最显著的一段商品。
- 本案例表现：只保留剑架和右侧剑身，遗漏左侧剑柄和左半段剑身。

### 2.2 IS-Net General Use

- 调用方式：`rembg` 2.0.77。
- 运行格式：ONNX。
- 模型名称：`isnet-general-use`。
- 当前用途：与 U2Net 并行生成第二个候选。
- 优势：对长条商品、细长连接结构和完整显著目标更稳定。
- 本案例表现：完整保留剑柄、整段剑身、挂绳和剑架。
- 已知问题：在某些盆栽图上会把一个连续商品分成两个组件。

### 2.3 SegFormer B0 ADE20K

- 模型：`nvidia/segformer-b0-finetuned-ade-512-512`。
- 框架：Transformers。
- 当前用途：语义限制，不直接生成最终 Alpha。
- 工作方式：把墙、地面、桌子、柜子等大背景类别从模型 Alpha 中排除。
- 最终结果始终是“原 Alpha 与语义允许区的交集”。
- 已知问题：ADE20K 是场景解析数据集，不是商品抠图数据集。
- 它可能把黑色剑架识别为 `base` 或 `table`。
- 因此代码加入了商品高度和底部保留门禁，不能让语义清理删除商品底座。

### 2.4 SAM 2.1 Hiera Tiny

- 模型：`facebook/sam2.1-hiera-tiny`。
- 框架：Transformers + PyTorch。
- 当前用途：框选路线的失败回退。
- 它不是默认最终结果。
- 只有双模型结果明显不完整或被判定为前后景反转时才启用。
- 输入是用户的框选矩形。
- 输出只贡献 Alpha，RGB 仍来自原图。

## 3. 直接抠图的完整执行顺序

直接抠图现在不再只运行 U2Net。

执行顺序如下：

1. 读取 EXIF 方向校正后的源图。
2. 使用 U2Net 生成全分辨率 Alpha 候选。
3. 使用 IS-Net General Use 生成第二个全分辨率 Alpha 候选。
4. 两个候选都与原始 RGB 重新组合。
5. 分别执行确定性 Alpha 清理。
6. 分别计算蒙版结构指标。
7. 比较两个模型的交集、并集和包含关系。
8. 如果一个结果几乎完全包含另一个结果，同时没有背景膨胀，则选择较完整的结果。
9. 对选中的结果执行受门禁保护的语义清理。
10. 透明边界裁切并保存 RGBA PNG。
11. 计算“自动可信度”，而不是输出虚假的 100 分。

## 4. 双模型完整度判断

设：

- `A` 是 U2Net 前景。
- `B` 是 IS-Net 前景。
- `I = A ∩ B`。
- `U = A ∪ B`。

计算：

```text
IoU = |I| / |U|
contain(A→B) = |I| / |A|
contain(B→A) = |I| / |B|
```

如果满足：

```text
contain(较小候选 → 较大候选) >= 0.94
1.02 <= 较大面积 / 较小面积 <= 2.80
较大候选不是 reject
较大候选结构分 >= 较小候选结构分 - 15
```

则把较小候选视为可能的残缺子集，选择较大的合理候选。

这不是简单地“谁面积大选谁”。

如果较大候选粘住相对两条边、覆盖几乎整张图或结构质量明显更差，它不会被选中。

## 5. 本次剑图为什么改选 IS-Net

真实统计如下：

```text
U2Net 高置信前景面积：95,739
IS-Net 高置信前景面积：157,012
U2Net 被 IS-Net 包含的比例：0.98372659
IS-Net 被 U2Net 包含的比例：0.59983313
两个蒙版 IoU：0.59393959
```

解释：

- U2Net 的 98.37% 都存在于 IS-Net 结果中。
- IS-Net 额外保留的不是随机背景，而是左侧剑柄和连续剑身。
- 因此 U2Net 是一个干净但不完整的子集。
- v3.13 选择 IS-Net。

盆栽案例的关系相反：

```text
IS-Net 被 U2Net 包含的比例：约 0.986
```

因此盆栽会选择 U2Net，不会强制所有图片都使用 IS-Net。

## 6. 确定性 Alpha 清理

模型生成 Alpha 后执行以下处理：

### 6.1 高置信前景

```text
confident = alpha >= 210
```

高置信区域用于估计商品主体和底部范围。

### 6.2 旧阴影抑制

如果商品下半部分外侧 Alpha 明显低于中心主体，并且外侧区域面积足够大，则将其视为源图旧阴影。

这一步只删除 Alpha，不修改 RGB。

### 6.3 连通组件清理

```text
binary = alpha >= 150
保留面积 >= max(12, 最大组件面积 × 0.0015) 的组件
```

目标是清除孤立噪点，同时保留把手、枝叶和装饰小部件。

### 6.4 窄范围羽化

保留组件经过约 `sigma=0.58` 的高斯羽化，重建窄抗锯齿边缘。

该处理不会扩大成大范围半透明光晕。

## 7. 语义清理及其保护门禁

SegFormer 找出场景类别。

默认背景类别包括：

```text
wall, floor, ceiling, sky, road, grass, water,
shelf, cabinet, counter, countertop, desk, table,
door, window, curtain, blind, step, base
```

非背景语义区域经过连接、闭运算和外轮廓填充后，形成“允许区”。

最终 Alpha：

```text
refined_alpha = original_model_alpha ∩ semantic_allowed_region
```

语义清理必须满足：

```text
0.38 <= 清理后高置信像素 / 清理前高置信像素 <= 0.985
清理后垂直跨度 >= 原跨度 × 0.68
清理后底部不能上移超过原跨度 × 0.18
```

任何一项不满足，就撤销语义清理，恢复模型原始 Alpha。

该门禁用于防止再次删除剑架、花瓶底座或商品下半部。

## 8. 框选后抠图

框选不是直接把框内所有像素设为前景。

执行流程：

1. 将归一化坐标转换为原图整数坐标。
2. 按框裁剪源图，不进行重采样。
3. 在裁剪图上同时运行 U2Net 和 IS-Net。
4. 使用相同的包含关系选择完整候选。
5. 执行安全语义清理。
6. 检查裁切结果相对于框选区域的高度覆盖。
7. 检查蒙版是否疑似前后景反转。
8. 失败时才调用 SAM2 框提示回退。

当前高度完整性门槛：

```text
裁切后非透明图高度 / 框选区域高度 >= 0.52
```

这个门槛只能发现“只剩顶部装饰”等严重错误，不能单独证明目标完整。

因此 v3.13 又加入了 U2Net/IS-Net 双模型完整度证据。

## 9. SAM2 候选选择

SAM2 可能返回多个候选蒙版。

候选目标函数：

```text
objective =
    predicted_iou
    - outside_share × 0.45
    - area_pressure × 0.90
    - incomplete_penalty
```

其中：

```text
incomplete_penalty = 2.0
```

如果最大连通组件没有从框选目标的上部延伸到底部，则视为不完整。

SAM2 回退只有一个提示模型，没有独立模型完整度证据，因此自动可信度最高限制为 89，不能显示 100。

## 10. 绿色盆栽专用旧阴影清理

只有检测到明确绿色主体时启用：

```text
HSV H: 26–80
S >= 55
V >= 18
绿色像素 / 前景像素 >= 0.20
```

算法保留：

- 绿色枝叶及其窄邻域。
- 每行连接到中心的花盆/底座主体。

算法删除：

- 花盆两侧不连接中心的棕色旧投影。

如果清理后保留比例小于 0.88 或大于 0.9995，则认为规则不可靠并撤销。

## 11. 当前结构分检查什么

结构分检查：

- 最大连通组件占比。
- 多余组件数量。
- 是否触碰裁切画布边缘。
- 前景覆盖比例。
- 软 Alpha 比例。
- 是否大面积粘住两条相对边。

相对边粘连规则：

```text
left > 0.45 且 right > 0.45
或
top > 0.45 且 bottom > 0.45
```

满足时通常意味着背景被保留、商品成为透明洞，直接 `reject`。

## 12. 新的自动可信度

结构分不能判断完整性，因此 v3.13 分成两个分量：

```text
structure_score
completeness_score
```

双模型完整度：

```text
completeness_score =
    clip(
        60
        + confirmed_smaller_mask_share × 25
        + IoU × 10,
        0,
        95
    )
```

最终：

```text
automatic_confidence =
    min(structure_score, completeness_score)
```

自动系统最高只能得到 95。

只有带人工真值 Alpha 的离线测试才能讨论 100 分。

本次剑图：

```text
structure_score = 100
completeness_score = 90.53256
automatic_confidence = 90.53256
界面显示：可信 91
```

## 13. 当前仍然解决不了的问题

### 13.1 两个模型可能犯同一个错误

如果 U2Net 和 IS-Net 同时删除同一个细部，模型一致性会错误升高。

### 13.2 没有真实 Alpha

没有标注真值时，无法计算 IoU、Boundary F-score、SAD 或 MSE。

当前分数只能叫可信度。

### 13.3 半透明和反射材质

玻璃、薄纱、烟雾、毛发和透明塑料不能仅靠二值连通性验收。

### 13.4 语义模型类别不适合商品

ADE20K 擅长场景，不擅长区分“黑色剑架”和“黑色桌面底座”。

### 13.5 SAM2 单框歧义

一个框中同时有商品、支架和背景时，SAM2可能只选其中一个实体。

## 14. 下一步最值得增加的能力

### 优先级 1：可交互正负点

框选后允许用户：

- 点一下“必须保留”。
- 点一下“必须删除”。
- 在 Alpha 预览上刷入/刷除。

这比继续调固定阈值更可靠。

### 优先级 2：第三个独立高质量模型

建议测试：

- BiRefNet General。
- BRIA RMBG 2.0。

第三模型应当加入离线基准后再进入生产，不应仅凭单张样例替换默认模型。

### 优先级 3：专用 Alpha Matting

在分割蒙版之后增加：

- ViTMatte。
- MatteFormer。
- Closed-form Matting。

它们应只优化窄边缘带，不能改写商品 RGB。

### 优先级 4：建立真实标注集

至少为以下类别制作人工 Alpha：

- 横向长条商品。
- 黑色商品与黑色支架。
- 绿色枝叶。
- 透明玻璃。
- 白色陶瓷。
- 带文字和细花纹商品。

离线指标建议：

```text
Alpha IoU
Boundary F-score
SAD
MSE
连通组件召回
文字区域保留率
人工完整性评分
```

没有这套标注，任何“90/100”都只能是启发式置信度。
