# 图片合格门禁（不可用“看着差不多”替代）

> 本文保留早期的验收目标与实验规范，不代表当前产物已通过。
> 当前交付逻辑以 `strict_compositor/quality.py` 为准；公开验证见 [VALIDATION.md](VALIDATION.md)。

一张交付图只有同时通过以下四类门禁，才可标记为 `pass`。

## A. 不可协商的像素与身份门禁

| 项目 | 合格线 | 失败处理 |
| --- | --- | --- |
| 输出 | 无损格式，当前正式交付要求长边至少 3840 像素，且通过输入绑定与其他门禁 | `reject` |
| 授权区外背景 | `changed_pixels = 0`，`max_delta = 0` | `reject` |
| 商品来源 | 严格路线使用原 RGBA 的确定性变换；混合路线仅在预先授权材质区采用候选，身份与结构硬恢复 | `reject` |
| 文字、花纹、轮廓 | OCR、轮廓和高频纹理无生成性漂移 | `reject` |
| 保护区 | 商品、阴影、倒影均不得覆盖电话、布料、桌边等区域 | `reject` |

## B. 几何门禁

| 项目 | 合格线 | 测量方式 |
| --- | --- | --- |
| 接触 | 每个商品至少 95% 的有效脚点与桌面支持面相交；最大连续悬空缝隙不超过 1.5 输出像素 | alpha 底部/支持面相交 |
| 摆位 | 主体不重叠，且不使用任何案例固定坐标 | 图层掩码和当前支持面 |
| 层级 | `z_order` 与遮挡关系一致 | 图层顺序检查 |
| 透视 | 商品基线、缩放和投影均与桌面平面一致 | 支持面/消失方向核验 |

## C. 光影门禁

| 项目 | 合格线 | 测量方式 |
| --- | --- | --- |
| 共同光向 | 三个商品投影主轴角度的最大差异不超过 8°，且与背景估计主光方向差异不超过 15° | 阴影主轴与场景光向 |
| 高度—位移关系 | 接触点位移为 0；同一物体上，高度较大的点投影距离不得更短（容差 2 px） | 像素高度图/脚点对应 |
| 接触阴影 | 仅覆盖真实基线邻域；核心最深，离基线单调减弱；不得使用统一椭圆 | alpha 基线距离场 |
| 投影 | 从脚点连续开始；不得出现在受光侧、不得穿过保护区；长度与物体高度和光仰角一致 | 投影射线与支持面 |
| 半影 | 只在硬投影后软化；远端不小于近端的模糊半径 | 距离分段 blur 统计 |
| 倒影 | 仅在被识别为有反射的平面启用；以基线为镜轴并随距离衰减 | 材质证据与镜像几何 |

## D. 视觉放行门禁

采用盲评，不展示算法名称或候选序号。评分维度为：

| 维度 | 权重 | 最低分 |
| --- | ---: | ---: |
| 接地感与投影物理性 | 30 | 85 |
| 商品身份与抠图边缘 | 25 | 90 |
| 色温/曝光/材质一致性 | 20 | 85 |
| 透视、比例、布局 | 15 | 85 |
| 背景完整性 | 10 | 100 |

总分必须 `>= 90/100`，且任一单项不得低于表中最低分；否则：

```json
{"verdict":"reject","batch_unlock":false}
```

## 泛化门禁

调参和验收必须分离。每次算法改动均在至少四类未参与参数选择的场景上运行：

1. 正视木桌/哑光台面；
2. 斜视桌面（明显透视）；
3. 玻璃或高光台面（倒影可能存在）；
4. 货架、柜内隔板或桌面有保护物的复杂场景。

任何一类的几何或像素门禁失败，或平均视觉分低于 90，均不允许以当前案例的好结果放行。
