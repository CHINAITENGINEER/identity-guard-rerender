# 首次公开整理

本次将历史研究目录整理为可下载、可检查和可运行演示的仓库。

- 保留核心算法、局部重渲染、适配器、公开测试与便携工具。
- 重写首页，新增算法说明、论文来源、验证记录和运行时说明。
- 新增完全由程序生成的离线示例，不依赖原照片或云服务。
- 拆分核心、工作台、模型、开发和浏览器依赖，并记录测试环境约束。
- 新增 Windows / CPython 3.13 的 GitHub Actions。
- 清空旧账号的默认抠图工作流 ID；浏览器回归改用环境变量和 Playwright 默认浏览器。
- 冻结运行时只清理 traceback 中的本机文件名元数据，详见 [RUNTIME.md](RUNTIME.md)。
- 修复 Windows 中文路径下 OpenCV 文件名写图失败：使用内存编码和 pathlib 写文件，
  增加灰度、RGB、RGBA 的 Unicode 路径无损往返测试。

不分发历史聊天、微信下载、商品原图、私人测试集、密钥配置、模型权重、
缓存和大量运行产物。原研究目录保留在本地，未被迁移或覆盖。

本次没有重写冻结的光影算法、训练新网络或宣称视觉交付已达标。
